# Problem Statement

## The Challenge
College students struggle with the fragmented process of event planning. Finding venues, designing themes, and writing professional copy requires significant time and diverse skills.

## The Need
An automated, intelligent assistant that handles the entire workflow—from research to final report—in a single click.

## Why Agentic?
A single LLM prompt cannot handle real-time web searches, creative design, and structured reporting simultaneously. An agentic architecture allows specialized agents (Research, Design, Copy) to use tools like Tavily and Gemini, while a Judge Agent ensures quality control.
